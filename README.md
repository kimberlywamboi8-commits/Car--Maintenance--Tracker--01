# DriveCare Garage

DriveCare Garage is a car maintenance tracker app built with HTML, CSS, and JavaScript.

## Features

- Dashboard overview
- Add and manage multiple vehicles
- Switch between cars
- Log fuel usage
- Log service history
- Log vehicle problems like:
  - Engine noise
  - Brake squeaking
- Service reminders
- Reports section
- Dark and light mode toggle

## Pages

- Dashboard
- Add Service
- Fuel Log
- Vehicle List
- Reports

## Built With

- HTML
- CSS
- JavaScript

## How It Works

The app stores data in the browser using `localStorage`, so each vehicle keeps its own:

- fuel logs
- service records
- issue reports
- reminders

## How To Run

1. Download or save the project files.
2. Make sure these files are in the same folder:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Open `index.html` in your browser.

## Project Files

- `index.html` - app structure
- `styles.css` - app design and layout
- `script.js` - app functionality
